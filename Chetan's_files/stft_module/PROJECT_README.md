## 📂 Project Modules

This repository contains multiple modules working together for noise cancellation:

### 1. 🎵 **STFT Audio Processing Module** (Contributor: Prakh)
**Status:** ✅ Complete & Production Ready
**Location:** `/stft_module/`

**Responsibilities:**
- Audio file processing using STFT
- Spectrogram generation (Magnitude, Power, Log, Mel)
- Spectral feature extraction
- Visualization and analysis

**Key Files:**
```
stft_module/
├── src/
│   ├── audio_loader.py        # Load and preprocess audio
│   ├── stft_processor.py       # STFT computation
│   ├── visualizer.py           # Plot generation
│   ├── main.py                 # Batch processing
│   └── test.py                 # Testing
│
├── docs/
│   ├── README.md              # Quick start
│   ├── QUICK_REFERENCE.md     # Cheat sheet
│   ├── HINGLISH_EXPLANATION.md # Hindi/English explanation
│   ├── PRACTICAL_EXAMPLES.md  # Code examples
│   └── ...
│
└── requirements.txt            # Dependencies
```

**What It Does:**
1. Loads audio files (16,000 Hz sample rate)
2. Applies STFT (2048 FFT size, 512 hop)
3. Generates 4 spectrograms per file
4. Extracts 5 features (Centroid, Rolloff, Flux, Power)
5. Creates visualizations
6. Saves data in ML-ready formats

**Output:**
- Numpy arrays (.npy) for ML models
- PNG visualizations
- JSON metadata

**Stats:**
- 1,444 files processed ✅
- 5,776 spectrogram arrays generated
- 100% success rate
