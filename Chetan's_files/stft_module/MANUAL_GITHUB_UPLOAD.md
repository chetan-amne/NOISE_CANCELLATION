## 🚀 STEP-BY-STEP MANUAL UPLOAD

### STEP 1: Go to GitHub
```
https://github.com/chetan-amne/NOISE_CANCELLATION
```

### STEP 2: Create New Branch
```
Click: "main" dropdown at top
Type: "feature/stft-audio-processing"
Click: "Create branch from main"
```

Now you're on: `feature/stft-audio-processing`

### STEP 3: Create Folder Structure
Click: "Add file" → "Create new file"

Type path: `stft_module/src/.gitkeep`
Click: "Commit changes"
Message: "Create stft_module structure"

### STEP 4: Upload Python Files (src/)
```
For each file in src/:
1. Click: "Add file" → "Upload files"
2. Select: audio_loader.py (from your computer)
3. Path: stft_module/src/audio_loader.py
4. Commit: "Add audio_loader module"
5. Repeat for:
   - stft_processor.py
   - visualizer.py
   - main.py
   - test.py
```

### STEP 5: Upload Documentation Files (docs/)
```
For each file in docs/:
1. Click: "Add file" → "Upload files"
2. Select: README.md (from your computer)
3. Path: stft_module/docs/README.md
4. Commit: "Add README"

Repeat for all 11 documentation files
```

### STEP 6: Upload Root Files
```
Upload to stft_module/:
1. requirements.txt

3. CONTRIBUTING.md
4. GITHUB_UPLOAD_GUIDE.md
5. etc.
```
